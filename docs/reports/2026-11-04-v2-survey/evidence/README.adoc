= Evidence for the 2026-11-04 v2 survey

These files back the findings in `../EPHAPAX-V2-ARCHITECTURE-AND-PLAN.adoc`. They are deliberately *outside* `formal/_CoqProject` and the Cargo workspace, so they change no build.

== Coq witnesses

`SurveyCounterexamples.v` is checked against the current `formal/` build:

[source,sh]
----
cd formal
coq_makefile -f _CoqProject -o Makefile.coq && make -f Makefile.coq -j4
coqc -R . Ephapax ../docs/reports/2026-11-04-v2-survey/evidence/SurveyCounterexamples.v
----

Expected `Print Assumptions` output with coqc 8.18.0. This was first checked at `800030f`, then re-checked after `main` (including #418) was merged into the branch at `10339b3`, with identical results:

[cols="2,3",options="header"]
|===
|Lemma |Assumptions
|`legacy_inconsistent` |axiom `Semantics.preservation` (legacy, `Admitted` by directive)
|`env_inconsistent_preservation_l1` |axiom `preservation_l1` (the `Admitted.` lemma)
|`env_inconsistent_step_pop` |axiom `step_pop_disjoint_from_type_l1` (the `Admitted.` lemma)
|`preservation_l1_FALSE_closed` |Closed under the global context
|`preservation_l1_FALSE_echo_crosspath` |Closed under the global context
|`observe_stuck` |Closed under the global context
|`pair_dup_linear_string` |Closed under the global context
|`echo_copyable_linear_mode` |Closed under the global context
|===

The first three rows mean the global environment can derive `False`. The L1 pair needs the P0 retirement in the plan. The legacy row needs decision D0b in the plan, because the legacy theorem is fenced. Both are owner decisions. The `Admitted.` must not be closed, and no side-condition may be added.
