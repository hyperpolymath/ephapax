== Ephapax

The public web home for this project is
https://ephapax.org[ephapax.org].

A dyadic language - one part affine, the other linear - as a type system
with safe memory management targeting WebAssembly.

Ephapax uses a compact, statement-delimited block syntax. Newlines act
as statement separators (equivalent to ;).
