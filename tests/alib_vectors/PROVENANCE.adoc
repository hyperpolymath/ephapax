= Pinned aLib conformance vectors

The six `*.json` files here are byte-identical copies of `vectors/<category>.json`
from hyperpolymath/aggregate-library, taken so that the ephapax conformer
(`src/ephapax-cli/tests/alib_conformance.rs`, plan rung E6) never reads another
repository at test time.

== Relation to the survey baseline

The 2026-11-04 survey measured a scratch conformer against aggregate-library
`48b7694` (154 vectors, read from the spec YAML): 89 pass / 1 fail / 13 out of the
I32 domain / 51 unimplemented. `a877c2e` differs in exactly two ways that move
those numbers: `logical/not` vector 3 now passes the condition `"not(true)"`
instead of the contradictory literal `true` (the 1 fail becomes a pass), and
`string/substring` gains two boundary vectors (154 to 156, both in the
unimplemented string group). Both commits have 29 operations; "22" was the
aLib v0.1.0 core count in its docs, not a different spec set.

Measured with the Rust/wasmtime conformer on these files: 90 pass / 0 fail /
13 skip out of the I32 domain (10 decimal + 3 string-valued `if_then_else`) /
53 skip unimplemented (30 collection + 23 string). The test
`alib_reproduces_survey_baseline_48b7694` undoes exactly the two vector changes
above in memory and asserts the survey's 89 / 1 / 13 / 51, with the one FAIL
being `logical/not#3`.
