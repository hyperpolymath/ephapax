== Positive controls

* M1: unit-valued region enters/exits; allocate and consume internally.
* M2: nested same-name scopes have distinct identities; inner exit preserves outer cells.
* M3: retain valid outer-region references while evaluating sibling; reject actual escape.
* M4: closed function crosses unrelated fresh region; compatible effectful applications compose.
* M5: unrestricted let and exactly-once linear consumption.
* M7: permitted observation of residue; forbidden illicit copy.

For each model, record explicit fragment boundaries. An unsupported constructor is not a successful regression rejection. Distinguish a typing rejection, configuration rejection, valid preserved transition, and completeness acceptance. Store-populated ClosedCex proves valid initial reads, not full source reachability or all configuration invariants.
