== tree-sitter-ephapax

Tree-sitter grammar for
https://github.com/hyperpolymath/ephapax[Ephapax] — a dyadic language
with affine and linear types.

=== Usage

[source,bash]
----
npm install
npx tree-sitter generate
npx tree-sitter test
----

=== Features

* Full syntax support: `+let+`, `+let!+`, `+region+`, `+@r+` annotations
* Highlights distinguish linear (`+let!+`) from affine (`+let+`)
bindings
* Region annotations (`+@r+`) highlighted as labels
* Local variable tracking for scope-aware navigation

=== File Extension

`+.eph+`
